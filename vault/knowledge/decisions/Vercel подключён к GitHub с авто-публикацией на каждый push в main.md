# Vercel подключён к GitHub с авто-публикацией на каждый push

**Решение:** владелец сам подключил репозиторий [[Лендинг собран статикой HTML+CSS+JS без сборки — решение из-за отсутствия Node.js|avicenna-food-landing]] к Vercel через вход "Continue with GitHub" и Import Project. Выбран режим — **авто-публикация на каждый push в main**, без отдельного подтверждения перед каждым деплоем.

**Почему:** так быстрее и проще для одного человека без команды — не нужно помнить про лишний шаг "запушить → потом ещё и задеплоить". Альтернатива (пуш в отдельную ветку, продакшен только после явного "ок, публикуем") была предложена, но отклонена в пользу простоты.

**Что это значит:** с 2026-06-28 правило CLAUDE.md "всегда спрашивать «Деплоим?»" для этого проекта снято для обычных коммитов — `git push` в main = сайт обновился. Подтверждение нужно только для нестандартных операций (force-push, удаление веток и т.п.).
