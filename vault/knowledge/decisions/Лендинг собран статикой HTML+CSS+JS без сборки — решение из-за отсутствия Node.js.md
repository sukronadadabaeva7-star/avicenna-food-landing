# Лендинг собран статикой HTML+CSS+JS без сборки

**Решение:** для лендинга [[Avicenna Food — натуральные фрукт-бары и фрукт-диски без сахара, глютена и пальмового масла]] выбран стек "HTML + CSS + JS (vanilla)" из двух вариантов, предложенных ТЗ (второй — React + Tailwind).

**Почему:** на машине пользователя не установлен Node.js (нет `node`/`npx`/`npm` в PATH, см. [[project_setup]] в памяти Claude Code) — React/Tailwind требуют сборку через npm, что сейчас невозможно без установки Node.js. Статика работает сразу, без сборки, и её проще задеплоить как есть (Netlify/Vercel/GitHub Pages из корня репозитория).

**Структура файлов:** `index.html`, `css/style.css`, `js/app.js` — в корне проекта.

**Что это значит для будущих изменений:** если позже установят Node.js и понадобится более сложная логика (бэкенд для формы заказа, реальная корзина с персистентностью, интеграция с Telegram-ботом для приёма заказов) — можно либо нарастить vanilla JS, либо мигрировать на React/Tailwind, пересобрав вёрстку по тем же токенам дизайн-системы из ТЗ.
